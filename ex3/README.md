# Домашнее задание к занятию "`Система сбора логов Elastic Stack`" - `Минаевой Екатерины`

### Задание 1

Вам необходимо поднять в докере и связать между собой:
- elasticsearch (hot и warm ноды);
- logstash;
- kibana;
- filebeat. <br> 
Logstash следует сконфигурировать для приёма по tcp json-сообщений. <br> 
Filebeat следует сконфигурировать для отправки логов docker вашей системы в logstash. <br> 
В директории help находится манифест `docker-compose` и конфигурации filebeat/logstash для быстрого выполнения этого задания. <br>   <br> 

Результатом выполнения задания должны быть:
- скриншот docker ps через 5 минут после старта всех контейнеров (их должно быть 5);
- скриншот интерфейса kibana;
